## 🚀 About Me

> *"Skills can be taught, but character cannot."*

I'm a **Computer Science grad student at University of Central Missouri** and a mission-driven Data Engineer who builds pipelines that don't just move data — they move decisions. With hands-on industry exposure at **Alten India** and deep expertise across the modern data stack (Airflow, dbt, Snowflake, Spark), I specialize in turning messy, siloed data into clean, governed, analytics-ready systems.

## 🏆 Project Highlights

### 🛡️ [Project SAVE — Community Hazard Reporting Platform](https://github.com/Rishwanth05?tab=repositories)
> **Why it exists:** Built after witnessing how dangerous road and infrastructure hazards go unreported in India — SAVE gives communities a real-time voice to flag and track risks before someone gets hurt.

A full-stack public safety app where users pin, photo-report, and filter live hazard incidents on an interactive map. Engineered with React + Vite, Node.js, PostgreSQL, Redis, MapLibre GL, and Docker — with JWT auth and CI/CD via GitHub Actions.

`React` `Node.js` `PostgreSQL` `MapLibre GL` `Redis` `Docker` `JWT`

---

### 🏠 [House Price Prediction — Rental Market Analyzer](https://github.com/Rishwanth05?tab=repositories)
> **Why it exists:** After struggling to find affordable housing during his first weeks of grad school in the US, Rishwanth built the tool he wished had existed — a data-driven rental price predictor for students entering unfamiliar markets.

A machine learning pipeline that ingests, cleans, and models rental listing data to surface fair price estimates by location. Combines EDA, feature engineering, and predictive modeling to help renters make smarter decisions backed by data, not guesswork.

`Python` `Scikit-learn` `Pandas` `SQL` `Jupyter`

---

### 🔍 [Crime Data Analysis — Urban Safety Intelligence](https://github.com/Rishwanth05?tab=repositories)
> **Why it exists:** Raw crime data is public but almost never accessible — this project transforms it into actionable geographic and temporal insights that could inform policy, planning, and personal safety decisions.

End-to-end data engineering and analytics project covering ingestion, transformation, and visualization of large-scale crime datasets. Built with a focus on reproducibility, clear schema design, and BI-ready output layers for Tableau/Power BI consumption.

`Python` `SQL` `Tableau` `Power BI` `Data Modeling`
